# Harvest existing source with Extrusion

Use Extrusion when the input is an existing extension source tree or supported SQL schema. Use [Package acquisition](maintain.md) for an existing JCB authoring graph and [application imports](imports.md) for business data. Extrusion creates or updates authoring definitions; it does not prove the original application's behaviour has been reconstructed.

**Source baseline:** JCB `6.x@037752c7e6599aa4cec900138dfb61af7ee4ba8f`, inspected 9 November 2026. The source-derived limits below are versioned findings. The supplied Clothing Store handover reports additional GUI observations; its companion build/checkpoint archives were not supplied with this documentation change, so those observations are not new runtime passes.

## Inputs and execution

1. Preserve the original source and schema, record their revision/hash, and work in the chosen authorized JCB target. Keep an export or backup of definitions that may be replaced. Record the target component, layout/version, include/exclude scope and existing-record policy before saving.
2. Select the actual source root using the installed Extrusion picker. The modern map reads `admin/forms/{view}.xml` and `admin/sql/install.mysql.utf8.sql`, with administrator/site source and manifests in the [JoomlaFour map](https://github.com/joomengine/Joomla-Component-Builder/blob/037752c7e6599aa4cec900138dfb61af7ee4ba8f/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Extrusion/Layout/JoomlaFour.php). [JoomlaSix](https://github.com/joomengine/Joomla-Component-Builder/blob/037752c7e6599aa4cec900138dfb61af7ee4ba8f/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Extrusion/Layout/JoomlaSix.php) inherits that map. A form-only scaffold is not a working extension. A schema dump is parsed as source, not executed to discover its columns.
3. Harvest and inspect the report before writing. Review every pairing: reuse, update, create or skip; inspect shared Fields and existing target identities. The [Extruder](https://github.com/joomengine/Joomla-Component-Builder/blob/037752c7e6599aa4cec900138dfb61af7ee4ba8f/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Extrusion/Extruder.php) separates `harvest()`, `candidates()` and `extrude()`, supports a dry run and can create a component root. Use the installed UI/MCP contract for these stages; do not invent endpoint names from PHP method names.
4. Apply the reviewed plan, then reopen the component, every affected Admin View, Field and attachment. Check actual saved GUIDs, shared consumers, data types, defaults, indexes, required/nullable values and enable flags. Save/reopen any corrected definition. The handover observed an integer length left at “None Set” blocking a later editor save; if encountered, choose the supported length/Other control without silently changing type or range.
5. Complete the missing application contracts: [GUID relationships](application-identities.md), [modal selection](modal-relationships.md), [normalized child storage](normalized-subforms.md), permissions, services/callers, imports and [API selection](../models/api-selection.md). Import/export ACL inference or a discovered table does not establish those features.
6. Compile. Compare source DDL with generated install/update SQL, then install on a disposable consumer and inspect the actual schema. Test representative CRUD and relationship cases, including the negative cases below. Seed INSERTs retained in an Admin View are not evidence that an installer executed them; inspect emitted SQL and fresh-install rows separately.

## Identity and sharing

The [GUID resolver](https://github.com/joomengine/Joomla-Component-Builder/blob/037752c7e6599aa4cec900138dfb61af7ee4ba8f/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Extrusion/Resolver/Guid.php) preserves a supplied accepted identity and otherwise derives UUIDv5 from source coordinates in namespace `b7d0f1a2-3c64-4f18-9a5e-2f7c8d1b6e30`. Repeating the same source can therefore address the same definition. This native importer contract differs from manual allocation of a new UUIDv4. “No existing target selected” is not proof of globally new identities; inspect planned identities and collisions before accepting a root or forced Create.

Fields can be shared across views. Before changing an extruded SKU's uniqueness, inspect all attachments: catalogue SKU uniqueness and an order-line compound key are different requirements. Reuse unchanged definitions; split an independently adapted Field under a new definition GUID and remap only its intended consumers. Do not assign a new application-row GUID to an authoring definition.

## Losses that need explicit correction

| Source-derived finding | Required action and acceptance |
| --- | --- |
| `CreateTable::clause()` gives every column in a UNIQUE clause rank 2; `Record::indexes()` converts rank 2 to each Field's unique setting. A compound UNIQUE can become independent unique columns. | Preserve the intended compound constraint through maintained SQL/installer source; remove only unintended individual constraints. For `(order_reference, sku)`, accept two SKUs in one order and the same SKU in another order; reject the exact duplicate pair. Inspect installed indexes as well as inserts. |
| FOREIGN KEY, CHECK, FULLTEXT and SPATIAL clauses do not become column-key metadata in this parser. | Inventory and retain required constraints/indexes explicitly. Test generated and installed schema; do not claim DDL round-trip fidelity. |
| `Sharing::identity()` includes `db_default` but omits `db_default_stated`, while `Record::defaults()` distinguishes it. | Compare otherwise identical columns with no DEFAULT and `DEFAULT ''`; split incorrect sharing and preserve each intended default. This is a source discrepancy, not evidence that a specific live database lost data. |
| Shared definitions can combine consumers that need different final semantics. | Inspect attachment GUIDs and split independent adaptations before changing shared type, default, index or validation rules. |
| Component-to-view API selection defaults to 0 in the Extrusion writer. | Select intended admin APIs explicitly and audit all generated routes, including dynamic resources. |

Sources: [SQL CreateTable](https://github.com/joomengine/Joomla-Component-Builder/blob/037752c7e6599aa4cec900138dfb61af7ee4ba8f/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Extrusion/Reader/Sql/CreateTable.php), [Record](https://github.com/joomengine/Joomla-Component-Builder/blob/037752c7e6599aa4cec900138dfb61af7ee4ba8f/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Extrusion/Resolver/Record.php), [Sharing](https://github.com/joomengine/Joomla-Component-Builder/blob/037752c7e6599aa4cec900138dfb61af7ee4ba8f/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Extrusion/Resolver/Sharing.php), [component-view writer](https://github.com/joomengine/Joomla-Component-Builder/blob/037752c7e6599aa4cec900138dfb61af7ee4ba8f/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Extrusion/Writer/ComponentAdminViews.php).

## Failure recovery and completion

An empty harvest requires checking the selected root/layout, recognized files, include/exclude scope and report; do not immediately write a second guessed graph. The handover's relative-path failure was environment-specific, not a universal ban on relative paths. A partial write requires inspecting persisted identities before rerunning, because deterministic identity and existing-item policy affect replacement.

Deliver the saved graph map, source/generated schema comparison, corrections and actual compile/install results. Preserve a failed specimen and a small synthetic reproduction for [human-led upstream reporting](../../testing/reporting-issues.md). Large integer columns surviving harvest do not prove safe money arithmetic, PHP integer width or JavaScript exactness; validate the consuming domain code separately.
