## Verification limits

The source contract and referenced catalogue metadata were inspected. The 13 offline mapping-inspector checks, Bash syntax checks and ShellCheck passed on 2026-11-03. The offline helper validates its documented input profile and reports an unexpanded mapping; it does not reproduce the compiler's PHP injector, Joomla autoloading, source precedence or API behavior. Its tests use disposable modified copies of the existing reference identity, never new public identities.

Joomla Power import/refresh, compiler output, aliases, installation and runtime have **not been exercised for this change**. Follow [integration acceptance](workflows/validate-and-integrate.md) and record each result before claiming those stages pass. The existing Playground evidence for another model does not validate Joomla Powers.

When the target changes, compare Table/form/Remote Config and compiler selection/injection first, refresh the catalogue through the network procedure, and inspect the specific mapped APIs in the target Joomla source. Do not infer method compatibility from an unchanged namespace or the catalogue's all-version row.
