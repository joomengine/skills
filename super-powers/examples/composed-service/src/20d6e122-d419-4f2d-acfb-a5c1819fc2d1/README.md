# UnitPriceProvider

Documentation fixture `20d6e122-d419-4f2d-acfb-a5c1819fc2d1`: an interface that supplies server-side prices by variant SKU in integer minor units for one caller-selected currency. Missing variants throw `OutOfBoundsException`. The PHP name is derived from the portable namespace in settings. See the [complete fixture](../../README.md) for use, licence, checks and limits.
